📖 How the System Works

Accelerometer: measures movement and vibration. Gyroscope: measures rotational movement. Orientation: estimates device position. GPS: provides location and speed where available. Microphone: requests audio access for future acoustic-event detection. Battery: indicates remaining power.

The current prototype uses explainable rule-based detection so it can operate offline. The architecture can later accept a trained on-device ML model.

🧠 Manual Threat Classification

Enter observed conditions. The system assigns a risk score and explains why the condition was classified as normal, warning, or emergency.

🚨 Emergency Alert System

Generate a distress message containing the current risk, time, battery and latest GPS information. On Android, the SMS button opens the phone messaging application with the recipient and message prefilled for review and sending.

📊 Threat Detection History

Records are stored locally on the device. No internet connection is required to retain history.

⚓ About FisherSafe

FisherSafe is a student research prototype for offline maritime threat detection and emergency alerting for small-scale fishermen in remote, low-connectivity environments.

Research Features

  • Multi-sensor monitoring
  • Explainable local threat classification
  • Offline local storage
  • Emergency alert preparation
  • Research data export
  • Future on-device ML integration

Important: This prototype is a research aid and should not be treated as a replacement for established maritime emergency services.
